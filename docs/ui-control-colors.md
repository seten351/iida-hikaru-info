# UI操作部分の標準配色

今後のchip、button、select、filter、検索UIの新規実装・改修は、この文書を配色の基準とする。背景、余白、角丸、文字サイズ、レイアウト、操作の意味は各コンポーネントの既存設計を維持し、色の役割を共通化する。

## 基本方針

トップページの検索UIを基準に、ピンクを主操作・選択のアクセント、プラム／ダークグレーを通常の文字、白〜アイボリーを操作面に使う。注意喚起は専用のバッジ・文言で表し、選択と区別する。

トップのブランド色 `--accent: #d95f76` と同系統の、少し濃い `--control-accent: #c14962` を白文字付き操作面に使う。白文字とのコントラストはそれぞれ3.59:1、4.78:1。ブランド色自体は維持し、小さい白文字を載せる操作部分では後者を使う。

今回の適用範囲はトップページと `/deadlines` の検索入力、select、検索ボタン、条件クリア、スマホの詳しく絞るボタン、および `/deadlines` の目的別chips・種別chips。トップの検索CTAも `#c14962`＋白文字、placeholderも `#706872` に統一し、通常サイズの文字のコントラストを確保する。ブランド装飾・背景・注意喚起色は維持し、新着・管理画面など他ページの操作部は一括変更していない。

## 色と役割

トークンは `src/app/globals.css` で定義する。トップと受付・販売一覧の操作部分の適用ルールは `src/app/deadline-redesign.css` に置き、`#top > .appearance-filters` と `.deadline-list-controls ~ .appearance-filters` に対象を限定する。

| 役割 | 使用色 | 用途 |
| --- | --- | --- |
| 操作面 | `--surface: #ffffff` / `--background: #f8f6f3` | 未選択chipは白、入力・select・副操作は既存のアイボリー背景 |
| 通常文字 | `--plum: #573849` / `--foreground: #272229` | 操作ラベル・入力値はプラム、通常本文はダークグレー |
| 補助文字 | `--muted: #706872` | フィールド名、説明、placeholder |
| 操作部の境界 | `--control-line: #d8cbd2` | 未選択chip、入力、select、条件クリアの薄い境界線 |
| 選択・主操作 | `--control-accent: #c14962` + `--surface: #ffffff` | 選択chip、検索CTA、展開中の詳しく絞るボタンの背景＋文字 |
| hover面 | `--accent-soft: #fff0f3` + `--plum: #573849` | ごく薄いピンク背景＋濃いラベル |
| focus | `--accent-dark: #a83b51` | キーボードfocusのoutline、入力・selectのfocus境界 |
| disabled | `#a69da3` / `--surface-soft: #f2eeea` | 無効な文字・操作面（詳細は状態表） |
| ブランドアクセント | `--accent: #d95f76` | 既存の装飾・ブランド表現。白文字付き操作面には上記control-accentを使う |
| 本日終了の注意喚起 | 背景 `#ffdfdf` + 文字 `#a12739` | 本日締切・本日販売終了などの既存バッジ |
| 間近の注意喚起 | 背景 `#fff1da` + 文字 `#855017` | 締切間近・販売終了間近などの既存バッジ |

## 状態ごとの適用

| 状態 | 背景・文字・境界 | 適用対象・扱い |
| --- | --- | --- |
| 通常／未選択 | 白〜アイボリー＋プラム文字＋control-lineの境界 | 未選択chip、入力、select、副操作。placeholderはmuted |
| 選択中 | control-accent背景＋白文字。chipの境界もcontrol-accent | 目的・種別chipの選択。「未終了」「すべての種別」も同じ通常の選択状態として扱う |
| 展開中 | control-accent背景＋白文字 | 詳しく絞るボタンの `aria-expanded="true"`。閉じた状態は既存の透明背景＋プラム文字 |
| hover | accent-soft背景＋プラム文字 | 有効なchip、button、入力、select。選択chip・主CTAの境界はcontrol-accentを保ち、未選択chip・副操作はcontrol-lineを保つ |
| focus | accent-darkの3px outline | 既存のfocus表示を維持。chip・buttonは3pxのoffset、入力・selectはoffset 0＋accent-dark境界。背景・文字はその時点の通常／選択／hoverに従う |
| disabled | 主CTAは `#a69da3` 背景・境界＋白文字。条件クリアは既存アイボリー面＋ `#a69da3` 文字。入力・selectはsurface-soft面＋ `#a69da3` 文字 | 実際に無効なネイティブcontrolsのみに適用。有効な操作のhover色を適用しない |
| 主CTA | control-accent背景・境界＋白文字。hoverは薄いピンク＋プラム文字 | 検索・確定など、画面の主要な操作。選択色と同じ色族で主操作の統一感を作る |
| 注意喚起 | 上表の専用バッジ色＋状況を示す文言 | 締切・販売終了の緊急度。既存バッジ、カードの強調色は維持し、単なる選択には流用しない |

hover中の選択chipはピンクの境界を維持する。`aria-current` 等の選択を示す属性も維持し、色だけで意味を伝えない。focusはhoverと併存させ、outlineを消さない。無効状態はネイティブの `disabled` 等で操作不能も示す。将来リンク型chipを無効化する場合は、色を薄くするだけではなく操作・キーボード・支援技術向けの状態を設計する。

背景と文字が同時に切り替わる配色では、背景だけをフェードさせない。今回のchipと検索CTAは `transition-property: border-color` とし、hover切り替え途中に白文字＋薄い背景が生じるのを避けている。

## 使わない組み合わせ

- 濃いプラム背景＋赤／ピンク文字を選択表示に使わない。
- `#d95f76` 背景＋白文字を通常サイズの操作ラベルに使わない（3.59:1）。
- `#c14962` 背景＋プラム文字を使わない（2.13:1）。選択中・主CTAは白文字にする。
- 白〜薄いピンクのhover面に白文字を載せない。hoverでは背景とラベルを一緒に切り替える。
- control-accentをアイボリー背景上の通常サイズ本文色に使わない（4.43:1）。通常文字はプラム／ダークグレーにする。
- 赤・オレンジの注意喚起バッジ配色を、デフォルト選択や通常のfilter選択に使わない。
- disabled色やopacityで、有効な操作・選択・補助説明を薄くしない。
- focusを色の変化だけで済ませたり、outlineを消したりしない。

## コントラストと確認方法

[WCAG 2.2の文字コントラスト基準](https://www.w3.org/TR/WCAG22/#contrast-minimum)に沿い、通常サイズの有効なラベル・placeholderは4.5:1以上を確認する。focus outlineは隣接する外側の操作面と3:1以上を確認する。薄い境界線そのものを、選択やfocusを示す唯一の手掛かりにしない。

| 組み合わせ | コントラスト比 |
| --- | --- |
| 白文字 / control-accent | 4.78:1 |
| プラム文字 / 白 | 10.16:1 |
| プラム文字 / アイボリー | 9.42:1 |
| プラム文字 / hoverの薄いピンク | 9.20:1 |
| muted文字 / アイボリー | 4.98:1 |
| muted文字 / hoverの薄いピンク | 4.86:1 |
| focus outline / 白・アイボリー・薄いピンク | 6.16:1 / 5.71:1 / 5.58:1 |

disabledはWCAGの非アクティブなUIの例外に該当するが、通常文字の配色には流用しない。outlineはピンクの操作面に直接重ねると十分な差がないため、chip・buttonの既存offsetを維持して明るい外側の面に表示する。

配色変更時はPC、スマホ、200%文字拡大で通常／選択／hover／focusを確認する。文字の切れ、水平スクロール、focusの隠れ、ラベルの読みにくさ、選択状態と注意喚起の混同を確認し、関連テスト・lint・型チェック・buildを実行する。

## 受付・販売一覧の初回確認記録（2026-10-02）

- ローカルPreviewで幅1440px・390px・320px、それぞれ通常表示と文字のみ200%拡大を確認。目的別・種別chip、検索、入力、select、条件クリア、スマホの詳しく絞るの計168状態を検証し、スクリーンショットで目視確認した。
- 有効な操作ラベルの最小比は4.78:1、placeholderは4.86:1、実際のfocus outlineと外側の面は5.71:1。無効状態はネイティブcontrolsにdisabledを付けて配色も確認した。
- 通常表示の操作部の寸法・余白・角丸・文字サイズは変更前と一致。各幅の文字200%でも横スクロールやchip・buttonの文字切れは検出されなかった。ブラウザのエラーは0件。
- `npm run test:deadlines`（60件）、`npm run test:public-ui`（57件）、`npm run lint`、`npx tsc --noEmit`、`npm run build` が成功。
- build後のローカル配信でもPC・スマホの選択／hover／focus色を照合し、目的・種別の切り替え、検索、条件クリアによるデフォルト復帰を確認した。ブラウザのエラーは0件。
- 締切・販売終了の注意喚起CSSを維持していることを差分で照合した。この確認記録は本番反映前に行ったローカル検証の結果を示す。

## 標準配色の確定方針

本番反映前の最終Preview確認で、旧トップ検索CTA（白文字／`#d95f76`）と旧placeholder（`#968d95`／アイボリー）の通常文字コントラスト不足を確認した。このためトップ検索UIも上記の標準配色に統一し、配色以外のレイアウト・操作は維持する。今後のUI操作部分にはこの確定した基準を使い、旧操作色を新しいcontrolsへコピーしない。

- 修正版のVercel Previewでトップ・受付一覧を幅1440px・390px・320px、それぞれ通常表示と文字のみ200%拡大で最終確認した。計264状態の配色を検証し、通常表示の操作部の寸法が修正前と一致すること、各幅・拡大状態で横はみ出しやchip・buttonの文字切れがないことを確認した。
- 有効なラベルは最小4.78:1、placeholderは最小4.86:1、focus outlineと外側の面は最小5.71:1。選択・未選択・hover・focus・disabledと、既存の注意喚起色が本基準に一致し、ブラウザのエラーは0件だった。
- トップへの適用後、締切テスト60件・公開UIテスト57件、lint、型チェック、buildを再実行して成功した。
- 修正版PreviewでPC・390px・320pxのトップ検索と受付一覧を実操作し、検索・シリーズ絞り込み・目的／種別切り替え・条件クリアによるデフォルト復帰を確認した。
